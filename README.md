# Система управления рецептами

## Описание
Проект представляет собой консольное приложение для управления рецептами. Основные возможности:
- Создание ингредиентов с проверкой корректности количества.
- Формирование рецептов и добавление в них ингредиентов (с автоматическим суммированием дубликатов).
- Масштабирование рецептов (изменение количества порций).
- Поддержка диетических рецептов (наследование).
- Формирование списка покупок на основе одного или нескольких рецептов с агрегацией ингредиентов.

## Установка
Для работы с проектом рекомендуется использовать виртуальное окружение.

1. Клонируйте репозиторий:
   ```bash
   git clone <ссылка-на-ваш-репозиторий>
   cd HW2
   ```

2. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Использование
Основные классы проекта находятся в файле `recipes.py`. Вы можете импортировать их в свой код:

```python
from recipes import Ingredient, Recipe, ShoppingList
```

### Запуск тестов
Для проверки работоспособности проекта используются тесты на базе `pytest`. Запустить их можно командой:
```bash
pytest
```
